# Scanventory

Scanventory is a web-based inventory management application designed to help users manage and keep track of products and stock.

## Features

- View products and inventory
- Add new products
- Edit existing product information
- Delete products
- Store inventory information using SQL Server
- Scan product barcodes using a device camera
- Manage product barcode information

## Technologies Used

- C#
- .NET 9
- ASP.NET Core
- Entity Framework Core
- Microsoft SQL Server
- Visual Studio Code
- Git and GitHub

## Purpose

The purpose of Scanventory is to provide a simple inventory management system that makes it easier for users to keep track of products and stock. The barcode scanning functionality provides an alternative to manually entering product barcode information.

## How to Run

1. Clone the repository.
2. Open the project in Visual Studio Code.
3. Ensure the required .NET SDK and SQL Server configuration are available.
4. Update the database connection settings if required.
5. Run the application using the .NET CLI.
