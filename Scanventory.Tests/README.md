# Scanventory

Scanventory is a web-based inventory management system developed as part of the App Development 2 summative assessment.

## About

The purpose of Scanventory is to provide a simple way of managing products and monitoring stock levels.

The application allows users to add, edit, search for and delete products, as well as adjust stock quantities and monitor low-stock products.

## Features

- Product management
- Add products
- Edit products
- Delete products
- Product search
- Category filtering
- Barcode lookup
- Manual barcode entry
- Camera barcode scanning
- Stock adjustments
- Low-stock monitoring
- Out-of-stock detection
- Dashboard statistics
- SQL Server database
